# Ian Researcher Skill

**Ian Researcher Skill** 是一個專為串接「學術邏輯」與「工程實作」所打造的 AI 輔助 Agent。本技能旨在協助你處理碩士論文、技術報告與系統架構設計，確保你的研究產出不僅在工程上可行，在學術與國際標準（如 IEEE）上亦具備強大的防禦力。

---

## 🚀 核心功能與運作模式 (Operating Modes)

本 Skill 支援四大核心模式，可獨立呼叫或組合使用：

*   **🏗️ 架構與標準萃取 (Architecture & Standards Extraction)**
    *   **用途：** 從國際標準或技術文獻中提取系統組件、介面與合規限制。
    *   **專屬輸出：** 自動產出 **Mermaid** 語法繪製的 ER Diagram、時序圖或系統架構圖。
*   **💻 工程邏輯轉譯 (Engineering Logic Translation)**
    *   **用途：** 將抽象的學術演算法或標準條文（Shall/Must），轉化為具體的開發邏輯。
    *   **專屬輸出：** 結合你的技術棧，產出具備實作指導價值的 Python、SQL 或區塊鏈智能合約（Smart Contract）虛擬碼。
*   **📚 文獻探討自動化 (Literature Review Automation)**
    *   **用途：** 系統化梳理多篇文獻的研究痛點、方法論與研究缺口。
    *   **專屬輸出：** 直接產出可貼入 Overleaf 的 **LaTeX** 語法（包含 `.bib` 引用格式與 `\begin{table}` 比較表）。
*   **🛡️ 匯報與口試防禦 (Reporting & Defense Generation)**
    *   **用途：** 產出簡報大綱、講稿，並進行嚴格的學術防禦壓力測試。
    *   **專屬輸出：** 模擬口試委員視角，針對「效能瓶頸、標準合規性、資料延遲」等痛點提出尖銳提問（Claim-Evidence-Reasoning 架構），並提供技術擬答。

## 🛠️ 如何使用 (Prompt 指南)

你可以透過明確指定「模式」與「輸出格式」來喚醒對應功能。以下是實用範例：

**場景一：文獻拆解與架構視覺化**
> 「請開啟 **架構與標準萃取模式**，閱讀這篇 IEEE 3240.04 的綠電標準文件，找出憑證上鏈的必備資料欄位，並用 Mermaid 幫我畫出 ER Diagram。」

**場景二：無縫接軌 Overleaf 寫作**
> 「請開啟 **文獻探討自動化模式**，比較這三篇關於 RWA 代幣化的論文。請將它們的『共識機制、隱私保護、合規性』整理成比較表，並直接輸出為 LaTeX 語法。」

**場景三：高壓口試防禦模擬**
> 「請開啟 **口試防禦模式**，這是我第三章的系統架構草稿。請扮演嚴格的口試委員，針對我使用『混合式區塊鏈處理跨系統信任』的設計，提出 3 個最難防禦的效能或資安問題，並給我附帶證據的擬答。」

## 📐 證據與輸出紀律 (Evidence Discipline)

1.  **零幻覺原則：** 所有外部標準條款、數據與文獻結論皆須基於事實，絕不捏造測試數據或參考文獻。若缺乏資料，將明確標示研究缺口。
2.  **術語精準度：** 預設使用繁體中文輸出，但在演算法、協定、標準代號（如 IEEE 802.19.1）與專有名詞上，強制保留英文原文以確保學術精準度。
3.  **條文溯源：** 凡涉及國際標準之論述，皆會盡可能標註具體的章節或條款代號（Clause/Section），強化論述公信力。
